# Catálogo de Boxeo - Primera versión

Sitio estático en HTML5 + CSS3 + JavaScript vanilla.

## Abrir
Abre `index.html` directamente en un navegador moderno.

## Personalizar
- Nombre de tienda: `index.html` (buscar `[NOMBRE DE LA TIENDA]`).
- WhatsApp: configurado como +51 986 437 411 en `js/script.js`.
- Productos: `data/products.js`.
- Fotos: colocar archivos en `images/products/` y cambiar la propiedad `image` de cada producto.
- Banner: reemplazar el placeholder de `index.html` por una imagen real cuando esté disponible.
- Colores: `css/styles.css`, variables dentro de `:root`.

Los productos incluidos son DEMO y deben reemplazarse por datos reales antes de publicar.
